# Roadmap — PlayerPath

## Phase 1 — MVP: Core Profiles & Discovery
**Target:** 4–6 weeks | **Goal:** Testable app with auth, profiles, and search

- [x] Project scaffold & documentation
- [ ] Flutter project init with theme system (dark/light mode)
- [ ] NestJS project init with modular architecture
- [ ] PostgreSQL schema + migrations
- [ ] Elasticsearch index setup
- [ ] Redis configuration
- [ ] Auth module (Email signup/login, JWT, Google OAuth, Apple OAuth)
- [ ] Player profile CRUD with photo upload
- [ ] Club profile CRUD with badge/banner upload
- [ ] Player search with core filters (age, position, step, county, distance)
- [ ] Club search with core filters (location, league, step, distance)
- [ ] Basic matching algorithm (position + step + location)
- [ ] Compatibility percentage display
- [ ] Bottom navigation shell (Home, Search, Messages placeholder, Notifications placeholder, Profile)
- [ ] Glassmorphism UI components library
- [ ] Unit tests (core logic)
- [ ] CI/CD pipeline (GitHub Actions)
