# 004 PlayerPath

> The UK's easiest platform for grassroots football recruitment.
> LinkedIn × Transfermarkt × Tinder — for football.

## Purpose

Connect grassroots, semi-professional, and non-league football players with clubs, scouts, and managers looking to recruit talent.

## Overview

PlayerPath allows players to build complete football CVs with video highlights, statistics, and references. Clubs can search, filter, and discover players using powerful tools — including an AI-powered matching engine that scores compatibility.

Built for iOS and Android from a single Flutter codebase, backed by a NestJS API, PostgreSQL, Redis, and Elasticsearch.

## Goals

- Become the go-to recruitment platform for non-league and grassroots football in the UK
- Give every player — regardless of level — a professional way to showcase their talent
- Help clubs find the right players faster with AI-assisted matching
- Scale to hundreds of thousands of users

## Technology Stack

| Layer | Tech |
|-------|------|
| **Mobile** | Flutter (single codebase, iOS + Android) |
| **Backend** | Node.js / NestJS |
| **Database** | PostgreSQL |
| **Cache** | Redis |
| **Storage** | Cloud object storage (videos/images) |
| **Auth** | JWT + OAuth (Apple, Google) |
| **Realtime** | WebSockets / Socket.IO |
| **Search** | Elasticsearch / OpenSearch |
| **Maps** | Google Maps / Apple Maps |
| **Infra** | Docker, Kubernetes-ready, CI/CD |
